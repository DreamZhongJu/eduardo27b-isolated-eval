# T-025 离线增益差归因包（`evaluation/t025_gain_gap`）

按《T-009 增益差分析预案》第 2 节事先写好的判定规则，只读现有计数与结果文件离线判定自建三档迁移题增益低于论文 `+0.29` 的 7 个候选原因（A–G）。

## 约束与保证
- **零 GPU、零 API**：强制 `CUDA_VISIBLE_DEVICES=""`，不启动模型，不调用 Agnes。
- **纯只读输入**：不改动任何已有评测结果目录、代码或数据集，输出仅写入独立临时/运行目录。
- **严格脱敏**：终端输出、JSON 与报告均经 `assert_output_sanitized` 机械校验，不含任何题面、标准答案、学生作答文本或来源编号。
- **统计口径**：按来源（或按题）有放回 bootstrap 10,000 次，基础随机种子 `42`，并与 `paired_gain.py` 及 `summarize_base4b.py` 双实现交叉核对。

## 文件说明
- `attribution_core.py`：原因 A–G 分层、门槛过滤、分布重加权、配对/非配对 bootstrap、判定规则与脱敏断言。
- `run_t025_pro5000.py` / `run_t025_pro5000.sh`：Pro 5000 只读汇总入口。
- `run_t025_a100.py` / `run_t025_a100.sh`：A100 只读计数入口（27B 格式提取检查、27B/base 后测长度筛查、27B 对话诊断与运行配置）。
- `combine_t025_verdicts.py`：在 cu04 合并 Pro 5000 与 A100 的脱敏 JSON 回执并输出统一判定表。
- `test_t025_gain_gap.py`：假数据单元测试（边界、重加权权重、共有源配对、双实现交叉核对、脱敏防泄漏）。
