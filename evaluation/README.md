## 五卡评测的数据流

每个难度独立生成教师和学生的教学对话。学生就原题与所选迁移题生成作答；每个来源含前测、冷启动对照、后测等已冻结样本及本地回执。学生采样请求按空闲容量分发给两个本地学生服务；教学对话中的学生调用保留主学生服务。原提示、采样参数和身份绑定不因分流而改变；请求发生异常时不向另一服务盲目重发。生成记录与 Agnes 判分记录分别保存，`unknown` 不等于判错。

本版是固定五卡拓扑，**不具备运行过程中动态增卡或来源跨 worker 动态分摊**；每来源的采样并发仍受原配置限制。合成测试与单来源试点只能验证对应范围，实际 GPU 速度与长期稳定性需要现场测量。

## 运行与状态

在目标服务器使用已审核的独立代码目录、绝对路径和固定 commit。当前仍在运行的版本以其启动回执和目标机目录为准；不在其运行期间更新源码、模型或环境。需要换版本时先确认旧控制器和相关写进程已退出、结果目录锁已释放；中断可能留下 `partial` 或 `held`，不能当作已完成，也不允许静默覆盖。

中文状态程序是 [parallel_adaptive/status_cn.py](parallel_adaptive/status_cn.py)。在当前容器中将它单独下载到工具目录后，用 `/workspace/eduardo-vllm018/bin/python /路径/status_cn.py` 运行；默认核验当前五卡控制器、回执与 GPU 身份，输出各档汇总、配置角色和已确认的服务进程。它是只读工具，不需要更新或重启当前评测。此状态程序绑定现有实验的运行目录和控制器哈希，不适用于任意新任务；如果无法核验则显示未知。

状态中的“生成完成”“判分记录完成”和“未决作答”是不同指标。统计脚本仅读汇总，不能输出题目、答案、学生文本、密钥或原始日志。

教师、学生及其他本实验 GPU 服务合计最多使用 **6 张物理卡**；空闲判断只是快照，并不构成跨用户预约。运行前要遵守服务器分配，不能终止或占用其他用户的任务。容器退出会结束其中的后台进程；普通终端断开不会必然结束仍在运行的容器任务。

## 判分与未决

Agnes 判分只接收获准的题目、参考答案和学生作答三类内容。当前评测控制器会自动处理新的作答并对部分技术错误重试；已经落盘为 `unknown` 的历史判分不会自动重判。旧格式导致的明确结果可从回执单独核验与恢复；未经验证的候选、未决、截断和 API 异常均不能直接当作错题或有效判决。是否使用任何补判结果应保留原始记录、版本和身份绑定。

训练不在此目录；参见 [training/](../training/README.md)。目录整理前的历史说明见 [HISTORICAL_SETUP.md](HISTORICAL_SETUP.md)，该文件仅供追溯。
