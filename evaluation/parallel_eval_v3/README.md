# 并行评测与安全接力

此目录为独立新版本，不修改已运行的 `app/` 或 `agnes_eval_v2/`。保留原评测的数据、代码绑定、试点、作答、判分和来源级锁：简单档复用已有 pilot 和 EASY 原目录，中等、困难各自使用原定独立目录。每档教师和学生分别使用一张 A100 80GB。

默认最多同时运行两档，自动选择显存近乎空闲的四张 A100；卡不够时运行可用的跑道或等待，困难档在前一跑道结束并释放资源后接力。显卡占用会变化，启动前必须现场再次核验；未使用的卡不等于被独占。

在独立克隆中，使用原实验虚拟环境运行 `python parallel_eval_v3/coordinator.py` 即可按默认规则启动；`python parallel_eval_v3/coordinator.py --status` 仅显示状态与汇总数量。请让后台进程的 stdout/stderr 保存在容器站内，不输出题目、作答、对话或原始日志到站外。

为避免改动原实验的冻结 Git HEAD，应将本仓库另外克隆到独立目录；继续从 `/workspace/eduardo27b-isolated-eval` 读取冻结版评测代码。新协调器检查原总锁、旧进程与 watcher 已退出、冻结代码与输入身份一致、旧 pilot 合格及模型哈希正确，之后才接手。模型、数据、密钥、日志及结果不包含在仓库中。

评测结果全部留在原实验目录；已完成来源不会重新生成，未知或中断来源保留回执。单一 Agnes watcher 跨三档使用同一个自适应窗口，只把题目、参考答案、完整学生作答发给 Agnes；正确、错误、unknown 分开统计。账号如同时用于其他服务器，可能触发接口侧限流。API 请求失败可重试，服务端不保证去重计费。

三档各为独立教学对话，不是同一对话的严格配对试验。以真实 GPU 上的结果为准，不得把模拟测试等同实际运行。
