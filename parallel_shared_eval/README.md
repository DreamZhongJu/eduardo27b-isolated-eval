# 共享学生服务的独立评测调度器

本目录与冻结版评测代码分离。支持三台单卡教师加一台或两台单卡学生服务；每档使用独立 evaluator，学生服务按固定路由共享。先执行本机合成数据 smoke，再对每档至多一个新来源完成生成及判分门槛验证，通过后进入批量。旧来源结果和请求回执不覆盖；存在未完成或未知请求的来源保留并报告，不盲目重试。

启动前校验旧代码、数据和模型的冻结绑定，确认旧控制器与残留子进程不存在，并检查 GPU 和端口。运行中 watcher 异常独立重启，生成结果保留。只允许已验证的 Agnes 修复版相邻 watcher/judge 文件组合；输出仅保留站内。`status.py` 输出只读聚合快照，不依赖旧控制器的状态文件。

与旧方案相比，学生服务的请求合批顺序改变，固定随机种子也不保证逐字相同。真实 GPU 显存、长上下文、吞吐和判分数学质量不能由本机模拟测试证明。因历史 `unknown` 独立保存的补记候选不会自动并入旧统计，仍需单独核对和合并。使用相同账号的其他服务器不受本机五并发锁约束。

在本目录运行 `python3 -m unittest -v test_supervisor test_status` 仅使用合成样本及模拟服务，不调用真实 API 或 GPU。
