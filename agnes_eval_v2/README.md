# 双卡评测与 Agnes 判分

此包适配已有公开评测仓库与 499 组私有测试集。GPU 0 是 Eduardo-27B 教师，GPU 1 是 Llama-3.1-8B-Instruct 学生；Agnes 判分不使用 GPU。

先校验输入与权重并使用合成算术题检查 API，再用简单档首条来源验证完整作答与判分；试点须有 96 条生成与判分回执，且至少 48 条取得明确判定，避免判分接口大面积异常时启动全量。该来源保留计入简单档，其余 498 条和中、难两档各 499 条随后依次生成。三个难度各有独立的教学对话。每来源 96 条学生作答，原题和迁移题各分前测、冷启动对照、后测三种条件、每种 16 次。

判分模型 `agnes-3.0-flash` 仅接收题目、参考答案、完整学生作答与通用评分说明；不发送对话、来源 ID、日志或其他数据。其规则是判断完整最终答案，不要求 boxed；答案不完整判错，无法作出判断时保留 unknown。此规则不等同历史 GPT v5 局部截取规则。

判分并发窗口从 1 增至最多 5，遇到失败减半并退避，429 冷却 60 秒；请求最多四次尝试。每条记录有独立身份、请求哈希、请求意图、每次响应和最终结果；已确定判分不重判。通信不确定重发可能导致上游重复处理或计费，不能声称服务端幂等。错误/格式无法判断及重试耗尽保留 unknown，并非错。不同服务器共享账户的并发由服务器端限制或账号实际状态决定，此本地程序无法管控别的服务器。

密钥放容器内 `/workspace/.secrets/agnes_api_key`，仅判分程序从文件读取，勿将密钥置于命令行、环境变量、镜像、日志或 Git。当前方案是同容器内独立进程，不等于网络或同 UID 权限隔离。

运行 `/workspace/eduardo27b-isolated-eval/agnes_eval_v2/run.sh` 会创建唯一结果目录 `/workspace/results/own-test-499-v1`。该目录已存在时默认不会重复启动或覆盖；可在现有后台进程已退出时用 `run.sh --resume` 显式续跑，继续尚未完成的阶段并复用可验证的已完成回执。状态不明的生成请求、重试耗尽的 unknown 判分及来源级 HELD 保留，当前版本不会自动重新尝试这些记录。`status.py` 只输出聚合数，简单档已经合并 PILOT 和 EASY。具体题目、答案、对话和日志保留在站内。

在此机器上完成脚本语法、模拟控制流程和 15 项独立 Agnes 离线测试，尚未在目标服务器验证真实 API、双模型并存、20k 上下文或端到端 pilot。当前学生 vLLM 0.18/FP16 不等同旧站 vLLM 0.17 条件，结果需标注。
