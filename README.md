# Eduardo 数学迁移实验

本仓库保存数学迁移题的评测代码和配套环境配置。当前工作是使用论文教师 Eduardo-27B 和学生模型进行教学对话、学生作答与判分；训练相关功能单独规划，尚未在此仓库实现。

## 仓库结构

| 目录或文件 | 用途 |
| --- | --- |
| [evaluation/](evaluation/README.md) | 评测流程、Agnes 判分、运行控制器及诊断工具。 |
| [training/](training/README.md) | 预留训练功能目录；目前不是可运行的训练实现。 |
| [Dockerfile](Dockerfile) | CUDA 12.8.1、Ubuntu 24.04、Python 和 uv 基础环境，模型和评测依赖另行安装。 |
| [SOURCE_SELECTION.md](SOURCE_SELECTION.md) | 论文作者迁移题来源身份及哈希，不包含题目内容。 |
| [AGENT_GUIDE.md](AGENT_GUIDE.md) | 早期服务器交接说明；历史环境与运行细节以当前实验冻结配置为准。 |

仓库根目录的 `app`、`parallel_adaptive` 等旧路径是指向 `evaluation/` 的 Linux 符号链接，供已有代码路径兼容。旧版**固定 commit** 仍可按原地址取得；新提交中直接通过 GitHub 的 raw 接口读取符号链接路径可能只得到链接文本，请使用 `evaluation/` 下的实际文件，或完整克隆仓库。使用不支持符号链接的文件系统时请直接使用 `evaluation/` 下的路径。

## 当前评测版本

当前五卡评测入口见 [evaluation/parallel_adaptive](evaluation/parallel_adaptive/README.md)：3 张教师卡、2 张共享学生卡，同一来源的学生采样请求分发到两张卡。教学对话保留原设定，历史结果和样本回执不覆盖。它使用独立进程与结果目录锁；不得同时启动另一个控制器写同一结果目录。历史未决作答不会在本版本结束后自动重判，需单独处理。

GPU 使用遵守**本实验总计最多 6 张物理卡**，教师和学生卡都计入。当前五卡版等待 5 张符合条件的空闲 A100，并非运行中自动增减卡。显存与利用率检查仅是快照，不能保证跨用户独占；实际以服务器调度和管理员安排为准。双学生分流及调度变化可能改变随机采样轨迹，运行版本和路由需保留在本地回执中。

## 获取代码与运行

代码可以按照服务器规则单向下载到实验服务器。**不要更新、覆盖或重命名正在运行任务所使用的代码和环境**；另建目录取得所需版本，记录完整 Git commit，并核验代码、模型、输入数据和环境后再启动新任务。旧任务当前使用独立目录和绝对路径，不会因为更新此仓库自动切换。目录结构变更不改变已发布 commit 的内容。

基础镜像只提供 CUDA 工具链和 Python 环境，不包含 PyTorch、vLLM、模型、数据或 API 密钥；GPU 驱动由宿主机提供。依赖应在目标环境中安装并验证，先跑合成检查与单来源试点，再扩大运行。当前实验使用的模型、输出目录、启动命令、判分器版本及限流策略以对应运行回执为准，见[评测导航](evaluation/README.md)。

## 数据与访问边界

仓库**不包含正式题目数据、学生作答、实验结果、模型权重或密钥**。这些材料保留在目标服务器；可以对外汇报汇总数字和错误类型。按已获授权，仅可将判分所需的题目、参考答案和学生作答发送给 Agnes；师生对话、完整日志及其他原始数据不随请求发送，也不发送给其他外部服务。API 密钥通过站内受控文件提供，不写入代码、镜像、提交或日志。

本机判分并发设置最多 5，不代表多台服务器共用账号时的全局并发已经受控。需要按账户实际限制协调，遇限流须退避。服务器的其他网络和数据规则由管理员确定。
