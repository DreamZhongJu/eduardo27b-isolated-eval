# A 组六卡重启候选 v3

`a-restart-kit-v3.zip` 提供旧四卡聚合诊断、六卡只读预检、启动控制器、状态查看和本地测试。使用本目录的 SHA-256 校验文件核对归档。解包到独立目录，沿用目标容器已有环境、模型和数据。

容器内从候选包运行 `a_group_restart_v3/diagnose.py`，会输出固定分类与汇总指标。使用 `a_group_restart_v3/restart.py --check` 核对可用卡位和配置。获取包不会启动训练。单独批准后，才使用包内的启动入口。

包含代码、测试与操作文档。训练数据、题目、作答、对话、运行日志、检查点、模型权重和密钥保留在实验环境。
