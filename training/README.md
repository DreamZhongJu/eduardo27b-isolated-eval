# 训练功能

训练**数据生成**的流式原型见 [流式方案与运行说明](../STREAMING_TRAIN.md)。它使用 API 和学生推理生成数据，不更新模型权重；旧数据迁移、真实接口和 A100 端到端尚未验证。

此目录为未来训练代码及其配置预留。**本仓库目前没有可直接启动的训练流程**，当前的 Eduardo-27B 与学生模型任务属于评测和推理，不更新模型权重。

后续加入训练功能时，应分别记录基础模型与权重来源、数据版本和划分、训练参数、随机种子、环境版本、产物保存路径及恢复方式；未经核验不要将推理代码或未完成的原型标为作者的 DPPO 训练实现。

模型权重、训练数据、结果、日志和密钥均不提交此仓库。实际资源申请遵守服务器规则及当前本实验**最多 6 张物理 GPU** 的上限，不影响已运行的评测任务。训练方案、数据范围和运行资源尚需单独确定；本文件不提供启动命令。
