# 等待空闲显卡后启动共享学生评测

独立于冻结运行目录，支持校验一次模型文件后等待任意四张空闲 A100，自动启动三教师与一共享学生。等待时持有项目锁但不占显卡；只因显卡不足持续等待，代码、数据、端口和环境等其他错误会单独报告并停止。实际启动前复查绑定和设备身份；GPU 可用性检查和实际加载之间无法原子排除其他用户竞争。

保留旧结果和所有不完整回执，不擅自重跑历史 unknown；逐档先运行一个新来源的试点并等待判分，验证后自动处理剩余来源。真实长上下文、吞吐和判分质量仍需要现场验证。使用共同账号的多台服务器不能由本机并发锁保障账号全局上限。

后台日志路径需使用 `/workspace/results/own-test-499-v1/shared-supervisor-wait.log`，`status.py` 仅汇总状态。nohup 抵抗终端断开，容器停止或重启仍会结束进程。

执行 `python3 -m unittest -v test_supervisor test_status test_wait` 仅使用合成数据和模拟服务，不调用真实 GPU 或 API。
